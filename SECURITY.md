# Security policy

## Supported versions

Security fixes are provided for the latest published minor release.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email
**akode.eu@outlook.com** with the affected version, impact, reproduction steps,
and any suggested mitigation. Do not include confidential source documents.

The project aims to acknowledge reports within seven days. Publication and
fix timing will be coordinated with the reporter where practical.

DocxGen UI processes documents locally and has no telemetry. Any change that
introduces networking, remote content, or a broader native permission surface
requires explicit security review.
